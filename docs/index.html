See your AI's memory come alive.

memglow turns the Markdown memory of your AI tools — a basic-memory knowledge base, an Obsidian vault, any folder of notes — into a live 3D brain. When your assistant reads, searches or writes a note, the neuron lights up and a comet runs along its links.

Your assistant's memory, at a glance

Calm at rest, alive when something happens. Built for people who let an AI remember things for them — and want to see what it does with it.

Live assistant activity

Hooks for your AI tools — or an MCP proxy — report every read, search and write of a note. The note flashes in the colour of the action; comets run to its neighbours.

● read● write● search

Camera that follows

The camera glides to what the assistant touches, frames a search's results, then drifts back to the overview after a few quiet seconds.

Themes & sub-themes

Notes cluster by theme, with relay bubbles for sub-themes. Straight from frontmatter or folder names.

Private by design

Runs on localhost, reads your notes read-only, masks secret-looking lines. No CDN, no analytics, no outbound calls.

Zero dependencies

One command sets it up, one command runs it. Node 18+, no build step, no database. Or one Docker container.

Tune it live

Glow, names, spread, gravity, spacing, links at rest, auto-rotate. Find a note and fly to it. Everything stays in your browser.

Works with your AI tools

Each native hook was checked against its vendor's documentation. Tools without hooks go through the MCP proxy, and every write is picked up from the notes folder anyway. Only note names are sent, never content.

How it works

memglow watches a folder of Markdown notes and listens to a hook. Nothing else.

Quick start

Node 18 or newer. The installer finds your notes and your AI tools, backs up every file it changes, and memglow uninstall undoes it.

1 · Set it up 
npx memglow init
2 · Run it 
npx memglow
3 · Open it 
# then restart your AI tools
open http://127.0.0.1:4747

Just the demo: git clone the repository and run MEMORY_DIR=./demo/memory node server.js. Options, Docker and hooks by hand: see the README.
